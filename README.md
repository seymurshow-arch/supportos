## Google Schedule source

SupportOS can read the Support Team schedule directly from a separate Google Spreadsheet.

Required environment variable:

```env
GOOGLE_SCHEDULE_SPREADSHEET_ID=your_schedule_spreadsheet_id
```

The same `GOOGLE_SHEETS_CLIENT_EMAIL` and `GOOGLE_SHEETS_PRIVATE_KEY` are reused. Share the schedule spreadsheet with the service-account email as **Viewer**.

Before using Agent Mapping, run `AGENT_SCHEDULE_MAPPING.sql` once in Supabase SQL Editor. The Schedule page is read-only and pulls monthly tabs such as `August 26` / `September 26` directly from Google Sheets. Agent Mapping links schedule display names to LiveChat emails.
